# MyApplication1
This is an app about Smart Pantry (Manager) management system, which is Java-based.
It consist of a strict recipe-matching rule algorithm.
The user will be able to view available pantry list, view available ingredients, update ingredients and delete.
They can also add ingredients, store ingredients quantities and units, and view recipes that can be prepared from available ingredients. 
The system will also give suggested recipes to the user, track expiry dates of ingredients and configure application settings.
It uses persistent local storage SQLite as a database and is created using Android Studio with Java language. 
It aims to help users manage pantry and reduces food waste by suggesting recipes based on ingredients currently available.
On suggested recipes users can select a suggested recipe to view, it will show recipe name, description, required ingredients,
required quantities, measuring units, and preparation instructions.
And for the settings the screen will provide application preferences, including the expiry-alert settings.
The application screen contains, a pantry list, add/edit ingredients, suggested recipes, recipe detail, and settings.
Navigation is provided between the main application areas.
